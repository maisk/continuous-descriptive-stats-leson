# Μέσος όρος και απόκλιση με ολοκληρώματα

**Διάβασέ το online:** https://maisk.github.io/continuous-descriptive-stats-leson/

Εκπαιδευτικό υλικό που εξηγεί πώς υπολογίζονται τα βασικά περιγραφικά μέτρα
(μέσος όρος, μέση απόλυτη απόκλιση, διακύμανση, διάμεσος) για **συνεχή**
δεδομένα, με ολοκληρώματα αντί για αθροίσματα.

Το υλικό στηρίζεται σε οπτικές απεικονίσεις. Κάθε υπολογισμός αναλύεται σε
βήματα και κάθε βήμα έχει τη δική του γραφική παράσταση. Όλοι οι αριθμοί
υπολογίζονται με R και ελέγχονται με υπολογισμούς με το χέρι.

## Η βασική ιδέα

Όλα τα μέτρα, εκτός από τον διάμεσο, περιγράφονται με **έναν** τύπο:

```
∫ (ποσότητα) · (βάρος) dx
```

- **Μέσος όρος:** η ποσότητα είναι η ίδια η τιμή.
- **Μέση απόλυτη απόκλιση:** η ποσότητα είναι η απόσταση από τον μέσο όρο, |τιμή − μέσος|.
- **Διακύμανση:** η ποσότητα είναι το τετράγωνο της απόστασης, (τιμή − μέσος)².

Το υλικό ξεκινά από το πιο οικείο και προχωρά στο πιο αφηρημένο:

1. **Απλές συναρτήσεις** (2x, x², 2x − x²). Το ύψος της καμπύλης είναι η τιμή, και
   κάθε x έχει το ίδιο βάρος 1/(b − a). Είναι ο γνωστός μέσος όρος «άθροισε και
   διαίρεσε», σε συνεχή μορφή.
2. **Η μετάβαση.** Το ίδιο βάρος για όλα τα x είναι η ομοιόμορφη κατανομή. Αν τα
   βάρη δεν είναι ίσα, το βάρος γίνεται **πυκνότητα πιθανότητας**. Εδώ αλλάζει ο
   ρόλος του άξονα y: από τιμή γίνεται βάρος. Αυτό είναι το σημείο που μπερδεύει
   τους περισσότερους.
3. **Πυκνότητες** (κανονική, τρίγωνο). Ο ίδιος τύπος, με βάρος f(x).

## Τι να διαβάσεις

| Αρχείο | Περιεχόμενο |
|---|---|
| `continuous_descriptive_stats.html` | **Το κυρίως κείμενο.** Μέσος όρος, μέση απόλυτη απόκλιση, διακύμανση, από τις απλές συναρτήσεις στις πυκνότητες. Έχει ασκήσεις με λύσεις. |
| `median.html` | Συνοδευτικό: ο **διάμεσος**. Είναι χωριστά γιατί δεν ακολουθεί το μοτίβο «ποσότητα × βάρος»: ο άγνωστος είναι το όριο του ολοκληρώματος. |
| `normal_interval.html` | Συνοδευτικό: η **κανονική κατανομή σε διάστημα**. Κανονικοποίηση, και τι αλλάζει όταν η κατανομή δεν είναι συμμετρική. |

Ξεκίνα από το κυρίως κείμενο. Τα συνοδευτικά διαβάζονται μετά, με οποιαδήποτε σειρά.

Τα HTML είναι αυτόνομα αρχεία: οι εικόνες είναι ενσωματωμένες και οι μαθηματικοί
τύποι είναι σε MathML, που αποδίδει ο ίδιος ο browser. Ανοίγουν σε οποιονδήποτε
σύγχρονο browser χωρίς σύνδεση στο διαδίκτυο και μπορούν να σταλούν ως ένα αρχείο.
Οι σύνδεσμοι μεταξύ τους είναι σχετικοί, οπότε, για να λειτουργούν σε ιστοσελίδα,
πρέπει να βρίσκονται και τα τρία στον ίδιο φάκελο. Ο κώδικας R είναι κρυμμένος και ανοίγει με το
«▶ Κώδικας».

## Πώς φτιάχνονται

### Τι χρειάζεται

- **R** (δοκιμασμένο με 4.6), με τα πακέτα `knitr` και `rmarkdown`. Οι εικόνες
  χρησιμοποιούν μόνο τα βασικά γραφικά της R, χωρίς επιπλέον πακέτα.
- **Quarto** (δοκιμασμένο με 1.9).
- **GNU Make 4.3** ή νεότερο.

### Εντολές

```
make          # όλα: εικόνες + HTML
make images   # μόνο οι εικόνες
make html     # μόνο τα HTML
make clean    # σβήνει όλες τις εικόνες και τα HTML
```

Το `make` ξαναφτιάχνει μόνο ό,τι άλλαξε. Αν αλλάξεις ένα script, τρέχει μόνο αυτό
και στη συνέχεια ξαναδημιουργούνται τα HTML.

### Scripts που φτιάχνουν τις εικόνες

| Script | Εικόνες | Τι δείχνουν |
|---|---|---|
| `function_values.R` | `values_*.png` | Απλές συναρτήσεις: ορθογώνια που γίνονται ολοκλήρωμα (Riemann), μέσος όρος ως ορθογώνιο ίσου εμβαδού, διάμεσος, μέση απόλυτη απόκλιση σε 4 βήματα. |
| `bridge_visual.R` | `bridge_weights.png` | Η μετάβαση: ίσα βάρη → διακριτά άνισα βάρη → πυκνότητα, με τον μέσο όρο να μετακινείται. |
| `mad_visual.R` | `mad_steps_*.png`, `var_steps_*.png` | Πυκνότητες: μέση απόλυτη απόκλιση και διακύμανση σε 4 βήματα (κανονική, κανονική σε διάστημα, τρίγωνο). |
| `normal_mean_median.R` | `normal_mean_median.png` | Μέσος όρος και διάμεσος της κανονικής. |
| `normal_mean_median_interval.R` | `normal_mean_median_interval.png` | Μέσος όρος και διάμεσος της κανονικής στο [−0.5, 2]. |

Κάθε script τρέχει και μόνο του (π.χ. `Rscript mad_visual.R`) και τυπώνει τα
αποτελέσματα των υπολογισμών του.

### Για το GitHub Pages

Τα `index.html` και `.nojekyll` χρειάζονται μόνο για τη σελίδα στο GitHub Pages.
Το `index.html` στέλνει στο κυρίως κείμενο και, αν η ανακατεύθυνση δεν δουλέψει,
δείχνει συνδέσμους προς τα τρία κείμενα. Το `.nojekyll` λέει στο GitHub να σερβίρει
τα αρχεία όπως είναι, χωρίς να τα περάσει από το Jekyll. Δεν φτιάχνονται με το
`make`, και το `make clean` δεν τα σβήνει.

## Αν θέλεις να προσθέσεις παράδειγμα

- **Νέα απλή συνάρτηση:** πρόσθεσε μια κλήση `run(...)` στο τέλος του
  `function_values.R`. Η συνάρτηση πρέπει να είναι **αύξουσα**, γιατί ο διάμεσος
  υπολογίζεται ως h(μέσο του διαστήματος). Το script σταματάει με σφάλμα αν δεν
  είναι.
- **Νέα πυκνότητα:** πρόσθεσε μια κλήση `visualize_spread(...)` στο τέλος του
  `mad_visual.R`, με την πυκνότητα στο όρισμα `dens`. Αν το εμβαδόν της στο
  διάστημα δεν είναι 1, κανονικοποιείται αυτόματα.
- Κάθε νέα εικόνα πρέπει να μπει και στην αντίστοιχη λίστα στην αρχή του
  `Makefile`, αλλιώς το `make` δεν θα ξέρει ότι υπάρχει.

## Συμβάσεις

- Τα δεκαδικά γράφονται με **τελεία** (0.333), όχι με κόμμα.
- Στις εικόνες οι ίδιες έννοιες έχουν πάντα το ίδιο χρώμα:
  - μπλε για τη συνάρτηση ή την πυκνότητα
  - πορτοκαλί για την απόσταση από τον μέσο όρο
  - πράσινο για το εμβαδόν που ολοκληρώνουμε
  - για τον μέσο όρο: μαύρη διακεκομμένη γραμμή στις εικόνες των 4 βημάτων,
    κόκκινη γραμμή ή κόκκινο ▲ στις εικόνες του μέσου όρου και της μετάβασης
  - σκούρο πράσινο διακεκομμένο για τον διάμεσο
- Η πυκνότητα γράφεται ως **f(x)**. Γράφεται ως **g(x)** μόνο όταν είναι
  κανονικοποιημένη σε διάστημα, με $g = f / Z$.
